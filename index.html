Introduction

앳홈의 스킨케어 브랜드 THOME(톰)과 소형 가전 브랜드 MINIX(미닉스)의 비주얼 콘텐츠와 광고의 기획·제작을 총괄하고 있습니다.

메이저 광고 편집실의 에디터로 시작해 폭넓은 제작 인력 네트워크를 쌓았고, 바디프랜드에서는 에디터와 아트 디렉터를 겸하며 다수의 TVCF를 제작했습니다. 이후 프로덕션 APLE을 창업해 성공적으로 운영하며 현장에서 통하는 실력을 증명했습니다.

말로만 지시하는 디렉터가 아닙니다. 필요하면 직접 카메라를 들기도, 작업을 직접 하기도 합니다.
AI 역시 시대의 흐름에 맞춰 꾸준히 공부하고 검증된 방식을 실무에 적용하고 있습니다.

저는 예술을 한다고 생각하지 않습니다. 단순히 보기 좋은 결과물이 아니라, 브랜드의 성장으로 이어지는 크리에이티브를 만드는 것이 제 역할이라 생각합니다.

    새 프로젝트 추가
    사진·영상 레이아웃

    위에서부터 순서대로 보입니다. 항목마다 크기를 고르세요 — 전체 한 줄 / 1/2 두 개 나란히 / 1/3 세 개 나란히 / 자동 가로는 전체, 세로는 1/2. ★ = Works 카드 대표 (사진·영상 파일·YouTube 가능).

    사진·영상을 여러 개 골라도 됩니다
      레이아웃 미리보기

      사용 방법
      0. 처음 한 번 위의 사이트 폴더 연결을 눌러 SITE_yw 폴더를 선택하세요 (Chrome).
      1. 파일 불러오기를 누르고 컴퓨터 어디에 있든 원하는 사진·영상을 고르세요. (여러 개 선택 가능, 파일 이름 상관없음)
      2. 고른 파일은 사이트 폴더의 works/WORK_XX에 자동으로 복사되고(사진은 웹용 크기로 변환), 목록 맨 아래에 추가됩니다. 새 프로젝트면 새 WORK 폴더가 만들어집니다.
      3. YouTube·Vimeo 영상은 링크를 경로·링크 추가 칸에 붙여넣으면 됩니다. (YouTube는 사이트를 인터넷에 올린 뒤 페이지 안에서 재생되고, 내 컴퓨터에서 파일로 열었을 땐 YouTube로 이동합니다.)
      4. 크기·순서를 정하고 추가하기 / 수정 저장 → projects.js 저장을 누르면 완료됩니다.
